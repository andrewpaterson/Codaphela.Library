-- BaseLib --

The areas below follow the project's filter tree (BaseLib.vcxproj.filters).

Primitive and basic types
  Primitive types (PrimitiveTypes.h), data types, IntAndPointer
  Strings: CChars, immutable and external strings, helpers
  Date and DateTime
  GUIDs
  Type names, type conversion, type parsing, data I/O
  Pointer functions and remapping

Collections
  Arrays: block, template, primitive, embedded, bit, sorted, dense/sparse, red-black tree
  Lists and linked lists (including free-list linked lists)
  Indexes: memory index trees, accessors, data orderers
  Maps: block, primitive and string maps
  Sets
  Trees
  Searching (binary) and sorting (bubble, quick, Tim)

Geometric types
  Vec2/Vec3/Vec4 in each primitive width, 4x4 matrices, quaternions
  Lines: buckets, overlap, splitting, minimising

Memory
  Mallocators, memory manager, global and data memory
  Free lists, slab, reuse, scratch pad, stack and temporary memory
  Memory caches and circular lists
  Leak detection, counting and tracking allocators

Object life cycle
  Constructors, Killable, LifeCycle, Refered

Files
  File chains: disk, memory, buffered, hash/MD5, debug and stderr output
  File I/O, readers and writers
  Chunked, packed and naive files
  Copying and comparing
  CSV, text, Intel hex, properties and XML files
  File names, iteration, file systems, file utilities
  Durable files and the durable controller
  Log files
  Indexed data: index tree files, evicting caches, descriptors, named indexes

File systems
  FAT32 (also hand-written as W65C816 assembly in Fat*W65C816.asm / FatW65C816.inc)
  Underlying drives: file and memory

Database
  Codabase with ACID transactions (see CodabaseTransactions.txt)
  Sequences

Text
  Text parser and parser configs for C++, JSON and XML
  Markup documents
  Unicode encodings (UTF-8, UTF-16, Latin-1)
  Plain text editor
  Escape codes

Math
  Integer, float, character and fixed point helpers
  Arbitrary precision numbers, packed floats
  Random numbers (Mersenne Twister, std)
  Calculator: expression parsing and evaluation

Errors and logging
  Logger, log configs, error handling, debug output, printf redirection
  Windows and Linux error strings

Platform
  Threads, mutexes, condition variables, jobs
  Sockets
  Timers
  Windows headers, defines and version

Function calling
  FunctionCaller (generated *_Call.inl files)

Validation

Aardvark
  Preprocessor correctness test for compilers
